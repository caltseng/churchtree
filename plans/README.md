# Plan index

Current operational behavior is documented in README and docs/spec/product-spec.md,
with architecture, deployment and user scenarios under docs/. Plans are not a second
source of truth for implemented behavior.

- `desktop-explorer.md`: implementation decisions and later mobile/branching follow-ups.
- `belief-history-future.md`: intentionally future topic/controversy exploration.
- `data-collection-*.md`: research plans; use the historical-coverage standard and
  current audit before treating checklists as coverage proof.
- `scale-plan.md`, `zoom-*.md`, `engineering-discrete-zoom.md`,
  `expand-node-metadata.md`, `plan-data-collection.md`: historical proposals. Some
  proposed filenames, ID schemes and rendering choices were never adopted.

The Westminster study plan is a separate active research/implementation track under
docs/. A plan, template or populated field is not proof that study content has shipped.
