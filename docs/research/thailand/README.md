# Christianity in Thailand: research foundation

Researched **2026-11-24/25**; writer-reviewed **2026-11-25**. The latest
selected evidence describes **2023**, not conditions in 2026. This is a
sourced introductory foundation, not comprehensive or independently
peer-reviewed history.

| Contract | Boundary |
| --- | --- |
| Country/region | Present Thailand as an organizing boundary, with historically necessary Ayutthaya/Siam, Lanna, migration and regional jurisdictions |
| Period | Secure resident Catholic mission in 1567 through a 2023 legal-context snapshot; earlier contact is not ruled out |
| Traditions | Catholic, multiple Protestant/independent traditions, Adventist and modern Moscow-linked Orthodox histories; other ancient Eastern traditions not established by this research |
| Exclusions | A national institutional tree, exhaustive congregational/clerical lists, unverified medieval origins, present vulnerable-community locations, private personal data and copied assets |
| Delivery | Research and a separately authorized selected `/thailand-history/` timeline, reusing the shared country-history mechanism |
