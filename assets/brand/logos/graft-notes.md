# Main Branch logo studies

Open index.html to compare two grafting-in directions at 16, 24, 32 and 96 pixels on light and dark backgrounds. No option is applied to the site.

All marks: orange #EE852B; purple #8C62D6. Transparent SVG backgrounds; two solid colors only; no gradients, external assets or dependencies. Background colors belong only to the comparison page.

- **Grafted in**: An orange shoot enters from the lower right and meets the established purple trunk at a diagonal graft union. Orange continues upward through the join into a leaf: the emphasis is belonging and shared growth. The purple trunk remains continuous behind it. Files: option-05-grafted-in.svg and option-05-grafted-in-wordmark.svg.
- **The graft union**: A compact graph version of the same idea. An orange path enters from below and joins a purple timeline; the shared upper segment turns orange. One origin node, one incoming node and one continuation make the merge visible without a leaf. Files: option-06-graft-union.svg and option-06-graft-union-wordmark.svg.

Recommended starting point: 05 for the living graft metaphor; 06 for a simpler graph mark. Each symbol uses a 64 × 64 viewBox and can be used directly as an SVG favicon or image. Provide accessible alt text when the logo is a link. Wordmarks contain live system-font text; outline before a final identity handoff if fixed typography is needed. The standalone symbol contains no font dependency.
