# Main Branch logo studies

Open index.html to compare the original and tree-branch variation at 16, 24, 32 and 96 pixels on light and dark backgrounds. No option is applied to the site.

All marks: orange #EE852B; purple #8C62D6. Transparent SVG backgrounds; two solid colors only; no gradients, external assets or dependencies. Background colors belong only to the comparison page.

- **Original · living trunk**: The original upright purple trunk and orange offshoot, retained for direct comparison. Round endpoints keep the connection to a timeline and Git graph. Files: option-01-trunk.svg and option-01-trunk-wordmark.svg.
- **New · tree branch**: The same upright stem and sweeping orange offshoot as #1, with a short purple twig and a single orange leaf. The base node preserves the history-graph cue; the leaf makes the branch recognizable as something living. Files: option-04-tree-branch.svg and option-04-tree-branch-wordmark.svg.

Recommended starting point: 01 for favicon clarity. Each symbol uses a 64 × 64 viewBox and can be used directly as an SVG favicon or image. Provide accessible alt text when the logo is a link. Wordmarks contain live system-font text; outline before a final identity handoff if fixed typography is needed. The standalone symbol contains no font dependency.
