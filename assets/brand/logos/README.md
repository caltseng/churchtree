# Main Branch logo studies

Open index.html to compare three directions at 16, 24, 32 and 96 pixels on light and dark backgrounds. No option is applied to the site.

All marks: orange #EE852B; purple #8C62D6. Transparent SVG backgrounds; two solid colors only; no gradients, external assets or dependencies. Background colors belong only to the comparison page.

- **The living trunk**: A chronological trunk stays visible as a second path branches outward. Three solid nodes suggest origin, continuity and a new tradition. The simplest silhouette and strongest favicon. Files: option-01-trunk.svg and option-01-trunk-wordmark.svg.
- **The confluence**: A left-to-right timeline splits into two paths and rejoins. The open lens recalls a leaf or fish without becoming a literal religious symbol. Best for the history-and-relationships story. Files: option-02-confluence.svg and option-02-confluence-wordmark.svg.
- **The branching M**: Two stems meet through a central junction to draw an abstract M. Its shared origin reads as a branching canopy, while the straight segments feel like a compact network diagram. Best as a distinctive monogram. Files: option-03-canopy.svg and option-03-canopy-wordmark.svg.

Recommended starting point: 01 for favicon clarity. Each symbol uses a 64 × 64 viewBox and can be used directly as an SVG favicon or image. Provide accessible alt text when the logo is a link. Wordmarks contain live system-font text; outline before a final identity handoff if fixed typography is needed. The standalone symbol contains no font dependency.
