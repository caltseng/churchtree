# Main Branch logo

Selected direction: **Woodland solid**, the side-graft mark (selected November 14, 2026).

Use `main-branch.svg` for the symbol and SVG favicon, and `main-branch-wordmark.svg` for the horizontal lockup. These are copies of `option-11-woodland-solid.svg` and its wordmark, kept under stable names for site integration.

The continuous brown trunk represents the established history; the green shoot is grafted into its side, with two straw ties marking the union.

- Bark: `#9B7555`
- Leaf: `#6E9D50`
- Straw: `#D6B579`

Both assets have transparent backgrounds and use exactly three solid colors. The symbol is a self-contained vector with a 64 × 64 viewBox. The wordmark uses live system-font text; outline it in a vector editor if fixed typography is needed. Use the solid symbol at small sizes and provide accessible text when it is a link.

The selected symbol is used in the home, Church History and Westminster headers and as their SVG favicon. Shared `brand.css` styles the accessible text lockup; its text follows the active theme while the symbol keeps its fixed Woodland palette.

Previous explorations remain available in `index.html`, `branch-studies.html`, `graft-studies.html`, `natural-graft-studies.html`, and `side-graft-treatments.html`. The latter compares the selected Woodland solid mark with other palettes and outline treatments. Recommendations in older studies are historical.
